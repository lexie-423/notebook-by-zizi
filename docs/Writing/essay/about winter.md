# 一些关于冷空气的回忆
在经历大约六个月的夏天（我指的是穿短袖的日子）以后，秋天终于来了。今年气温的反常无不让人具体地感受到全球气候变暖的影响。当然在这里归咎于气候变暖可能不科学，也有可能是所谓厄尔尼诺现象，但我本人不是地理气象爱好者，就不做过多研究了。正如大家调侃的一样，浙江上海这些地方是没有秋天的，或者说秋天就这么几天。今年直接默默入冬，这两天已经是体感温度在15度左右了。说起来很奇怪，人对气温的适应让穿衣习惯变得有弹性。去年期末大约是5度左右吧，我可以只穿一件短袖一件衬衫，外面套个三合一出门，并且不穿秋裤。然而今年我在15度，恨不得晚上也要穿上秋裤。

冷空气骤的时候，总会有一些奇怪的思绪在心里搅动。直到昨天在小红书上看见一句话，就深以为然了:
> quote "广东最近的冷空气每吸一口都可以吸进所有的情绪。"

要问我喜欢夏天还是冬天，我肯定毫不犹豫地选择冬天。我是一个不太耐热但又不怎么出汗的人，最讨厌潮湿闷热的环境中，空气里暗流的热浪啃食我耐心带来的那种烦躁的感觉。在冬天，只要不停地给自己加衣服，总归不会冻死的。

停笔几天继续写，到了十月底，桂花姗姗来迟。今年的天气似乎总有异兆，桃花在一年当中被骗出好多次。如果我没记错，其实桂花在春天又被骗出过一次。时间过得真快啊，记忆还停留在春节，现在又进入新一年等待的时区了。吸入冷风中桂花香，就像早晨喝了一杯冰牛奶一样清爽。我对这样的回忆可能停留在高二以前了，因为和园并没有栽种桂花树。情感上。我更依恋檀枫新苑。小学时候，虽然看似学习抓得很紧，但我还是要有几分自由的空间。晚上去楼下摘桂花可以算作是一年期待的活动之一，摘完桂花我又有理由挑桂花蒂磨蹭一小时。小时候我记得我不喜欢吃桂花类制品，尤其是桂花年糕，因为桂花年糕总是出现在我进食物最困难的早餐。糖浆只附着在年糕外表，年糕内里毫无甜味。年糕在嘴里多咀嚼几下，珍贵的桂花糖味就流失殆尽，只剩下黏牙无趣的年糕。但是我这两天竟然开始想吃桂花年糕，可能最终只是想的时候最好吃，等真正端到面前，我也只能动几下筷子。可这又印证着人年纪大了慢慢会想家。毕竟我又只是二十岁，这种老式的特性在我身上出现会不会有点太早了些啊。
